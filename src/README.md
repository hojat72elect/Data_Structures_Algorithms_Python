# Linked List

A linked list is a linear collection of data elements, in which linear order is not given by their physical placement in
memory. Instead, each element points to the next.
A drawback of linked lists is that access time is linear. Faster access, such as random access, is not feasible. Arrays
have better cache locality as compared to linked lists.

![Linked List](../assets/linked-list.jpeg)

## Complexities

### Time Complexity

| Access    | Search    | Insertion | Deletion  |
| :-------: | :-------: | :-------: | :-------: |
| O(n)      | O(n)      | O(1)      | O(n)      |

### Space Complexity

O(n)
